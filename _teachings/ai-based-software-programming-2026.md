## Course Overview
This course teaches programming through the lens of AI applications. Students will:
- Become proficient in Python for data and AI work
- Train and evaluate machine learning models
- Integrate LLM APIs into working software
- Build and present a small AI-powered application
## Prerequisites
- None; the course starts from Python basics
